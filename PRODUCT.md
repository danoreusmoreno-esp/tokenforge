# Tokenforge — product

**What it is.** A browser tool to build a design system from scratch: Bases (goals, scope, principles), Foundations (colour ramps, roles, type, spacing, radius, elevation, motion, contrast audit), a 56-component catalogue mapped to nine reference systems, a Board, and exports (CSS, W3C JSON, Figma/Tokens Studio, Tailwind, AGENTS.md, BRIEF.md).

**Who uses it.** UX/UI designers who already know tokens and Figma (agency teams, e.g. Flat 101). Sessions of 20–90 minutes, desktop first, phone for review.

**Their job.** Turn a brief and one brand colour into a coherent, accessible system and hand it to code and Figma.

**Mode.** Operate (app UI). Precision and restraint; the brand being built is the only colour on screen.

**Language.** Spanish (Spain) UI; code exports in English.

**Constraints.** Static app (GitHub Pages and a claude.ai artifact), no backend, data in localStorage. Fonts only from Google Fonts.
